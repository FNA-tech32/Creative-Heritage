## 🏛️ About Creative Heritage

**Creative Heritage** is built on the philosophy that modern web engineering should honor aesthetic elegance while delivering computational speed and rock-solid architectural reliability.

The platform provides a comprehensive showcase of:
- **Custom Web Platforms**: Dynamic applications built with modern JavaScript, scalable APIs, and reactive interfaces.
- **Interactive UI/UX**: Particle mesh backgrounds, dynamic typewriting loops, 3D card tilt physics, and smooth scroll reveals.
- **Multi-Channel Contact Infrastructure**: Seamless integration of **Primary** and **Alternative** communication pathways ensuring 24/7 accessibility for clients and collaborators.

## 🛠️ Technology Stack

### Core Technologies
- **HTML5**: Semantic document layout, accessible ARIA attributes, Page Visibility event tracking.
- **CSS3**: Custom design tokens, Flexbox & CSS Grid, keyframe animations, glassmorphism accents.
- **JavaScript (ES6+)**: Asynchronous data fetching, dynamic component rendering, DOM event delegation.

### Libraries & Plugins
- **[jQuery 3.6.0](https://jquery.com/)**: Fast DOM traversal, event handling, and animation queues.
- **[Particles.js](https://vincentgarreau.com/particles.js/)**: Lightweight canvas particle constellation system.
- **[Typed.js](https://mattboldt.com/demos/typed-js/)**: Typewriting effect for dynamic hero subtitle highlights.
- **[Vanilla-Tilt.js](https://micku7zu.github.io/vanilla-tilt.js/)**: 3D gyroscope tilt effect on hover.
- **[ScrollReveal](https://scrollrevealjs.org/)**: Declarative on-scroll entry animations.
- **[Isotope](https://isotope.metafizzy.co/)**: Filterable grid layout engine for portfolio projects.
- **[EmailJS](https://www.emailjs.com/)**: Serverless email dispatch directly from client-side forms.
- **[Font Awesome 5.15.3](https://fontawesome.com/)**: Vector icon set for UI navigation, badges, and contact details.

## 🚀 Quick Start & Local Setup

Because Creative Heritage is crafted with vanilla web standards, it requires no complex compiler toolchain or heavy node runtime dependencies to run.

### Option 1: VS Code Live Server (Recommended)
1. Open the repository root folder in **Visual Studio Code**.
2. Install the **Live Server** extension (`ritwickdey.LiveServer`).
3. Right-click on `index.html` and choose **"Open with Live Server"**.
4. The website will automatically launch at `http://127.0.0.1:5500/`.

### Option 2: Python Built-In HTTP Server
```bash
# Navigate to the workspace directory
cd Creative-Heritage

# Run Python's built-in static server (Python 3.x)
python -m http.server 8000
```
Open your browser and navigate to `http://localhost:8000/`.

### Option 3: Node.js `serve` or `http-server`
```bash
# Using npx (no global installation required)
npx serve . -p 8080
```
Open your browser and navigate to `http://localhost:8080/`.

## ⚡ SEO & Structured Data

The website is fully optimized for modern search engines and social crawlers:
- **Semantic HTML5**: Clean document outline utilizing `<header>`, `<nav>`, `<section>`, `<article>`, and `<footer>`.
- **JSON-LD Schema**: Integrated `Schema.org/Organization` markup with multi-point contact specifications (`customer service`, `technical support`, geographic coordinates).
- **Open Graph Protocol**: Enriched `og:title`, `og:description`, `og:type`, and `og:site_name` tags for high-fidelity social previews.
- **Tab Visibility Engagement**: Automatic title switching invites users back when navigating between multi-tasking tabs.
